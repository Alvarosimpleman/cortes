O Cortes é um programa que roda no computador do próprio usuário. Ele analisa vídeos e transmissões que o usuário tem permissão para usar, cria clipes verticais curtos dos melhores momentos e, quando o usuário autoriza, envia esses clipes para a conta do próprio usuário no TikTok como rascunho. O usuário revisa e publica pelo aplicativo do TikTok.

O programa não é vendido nem oferecido a outras pessoas e não tem servidor próprio: tudo fica no computador do usuário.

Cortes is a desktop program that runs on the user's own computer. It analyzes videos and streams the user is allowed to use, creates short vertical clips of the best moments and, when the user authorizes it, sends those clips to the user's own TikTok account as drafts (inbox upload). The user reviews and publishes them in the TikTok app.

The program is not sold or offered to other people and has no server of its own: everything stays on the user's computer.
